# Справка для Иностранцев

## Описание

Сайт организации, которая помогает иностранным гражданам собирать документы для жизни, работы и учёбы
в России. На сайте пять тематических разделов на отдельных страницах и 16 сценариев, включая ежегодное уведомление по ВНЖ. Частые вопросы находятся на главной.

Пользователь переходит в раздел, выбирает сценарий и переходит к анкете, отвечает на вопросы и выбирает 'Есть' или 'Нет'
напротив документов. Кнопка 'Ответ' показывает предварительный список с пояснениями.

## Структура проекта

- 'index.html' — главная, описание организации, запись на приём по телефону, разделы и частые вопросы;
- 'residence.html', 'work.html', 'study.html', 'registration.html', 'family.html' — тематические разделы;
- 'questionnaire.html' — анкета выбранной карточки;
- 'images/' — логотип и изображения разделов;
- 'css/style.css' — оформление и адаптивность;
- 'js/data.js' — разделы, карточки, вопросы и документы;
- 'js/rules.js' — правила подбора документов;
- 'js/main.js' — работа анкеты, переключение тем и стрелка наверх;
- '.gitignore' — исключения для Git.

## Технологии и оформление

HTML, CSS, Bootstrap 5.3.8 и JavaScript. На каждой странице одинаковые шапка и подвал с контактами организации.
Для компоновки используются Bootstrap, Flexbox и CSS Grid. Проживание оформлено как справочник с боковым меню, работа — горизонтальными вариантами, учёба — маршрутом, миграционный учёт — ситуациями, семья — двумя зонами.
Классы оформлены по БЭМ: 'residence-panel', 'questionnaire', 'document-list', 'result'.
В CSS есть переменные, медиазапросы, состояния наведения и видимого фокуса.
Шапка закреплена через 'position: sticky', круглая стрелка 'Наверх' — через 'position: fixed'; она появляется после прокрутки на 400 px.

Вопросы меняются в зависимости от ответов. После изменения данных предыдущий
результат скрывается. Ответы хранятся до обновления анкеты или перехода на другую страницу.

## Запуск

Открыть 'index.html' в браузере.
