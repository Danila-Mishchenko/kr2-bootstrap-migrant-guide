# Справка для Иностранцев

## Описание

Справочник документов для иностранных граждан, которые живут, работают или учатся
в России. На сайте пять разделов и 16 карточек, включая ежегодное уведомление по ВНЖ.

Пользователь открывает карточку, отвечает на вопросы и выбирает 'Есть' или 'Нет'
напротив документов. Кнопка 'Ответ' показывает предварительный список с пояснениями.

## Структура проекта

- 'index.html' — страница, меню, анкета и частые вопросы;
- 'css/style.css' — оформление и адаптивность;
- 'js/data.js' — разделы, карточки, вопросы и документы;
- 'js/rules.js' — правила подбора документов;
- 'js/main.js' — вывод карточек и работа анкеты;
- '.gitignore' — исключения для Git.

## Технологии и оформление

HTML, CSS, Bootstrap 5.3.8 и JavaScript.
Для сетки используются Bootstrap-колонки, для меню — Flexbox.
Классы оформлены по БЭМ: 'guide-card', 'questionnaire', 'document-list', 'result'.
В CSS есть переменные, медиазапросы, состояния наведения и видимого фокуса.
Шапка закреплена через 'position: sticky', кнопка 'Наверх' — через 'position: fixed'.

Вопросы меняются в зависимости от ответов. После изменения данных предыдущий
результат скрывается. Черновики сохраняются до обновления страницы.

## Запуск

Открыть 'index.html' в браузере.
